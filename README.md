## About

Senior Software Engineer based in **Addis Ababa, Ethiopia**. I design and ship fintech systems — payment gateways, interoperable switches, remittance platforms, and multi-tenant SaaS — with a focus on latency, reliability, and clean architecture.

- Architected Ethiopia's first private IPS payment switch (**ArifSwitch** / Mojaloop) on **ASP.NET Core**
- Cut payment gateway latency from **5s+ to under 1s** with **Spring Boot**
- Built real-time remittance flows with core banking APIs (**CBE**, **Zemen Bank**)
- Integrated local & global rails: EthSwitch, PSS, M-Pesa, PayPal, USSD, and wallets
- Lead code reviews and mentor engineers around clean architecture and backend best practices
